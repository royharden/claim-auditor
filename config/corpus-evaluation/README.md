# Unadmitted dataset manifest templates

These files are source-only operator forms, not admitted manifests, measured studies, gold, receipts or passing examples. Null identity/version/cap fields and an empty case list deliberately fail strict manifest validation. No scoring or provider action has been run to create them.

Copy the forms to private operator-controlled paths after execution is authorized. Fill actual frozen source/run/prompt/model/code/protocol identities, declared caps and real ancestry/rights/custody/review provenance. Do not substitute zero hashes, invented model usage/prices, made-up human dates or fake receipt strings. Keep gold files and labels outside all source/inference/control trees; preflight opens every inference case first.

`DatasetCase` and `DatasetManifest` live only in `contracts.py`; these forms do not define a competing schema. Paths may be explicit local absolute paths or portable relative paths rooted at the operator manifest directory, with no traversal, URLs or UNC shares. Rights/custody receipt strings remain operator assertions, not verified controls. Locked mode needs actual prior admission and the exact per-case copied protocol. DEV descriptive mode cannot carry admitted-by/date metadata.

Use one predeclared representative per family/common ancestry cluster. Repeated source/content/run/family/ancestry/case identities refuse; the tool never chooses the best variant after inspecting results. Separate variant studies do not become new independent families. Every case must retain all four equal-packet arms and the separately labeled full-index utility, including explicit failure rows. Unknown observations remain unknown.

See [dataset evaluation](../../docs/dataset-evaluation.md) for the exact dormant API and future reproduction sequence. No actual hidden corpus, human work, custody, paid calls, provider key or environment is supplied here.
